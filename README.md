# Yobunjung (AI 기반 분리수거 가이드 & 재활용 로그 시스템)

## 📌 프로젝트 개요
Yobunjung은 사용자의 분리수거 습관을 개선하기 위해 개발된 AI 기반 분리수거 가이드 플랫폼입니다.  
모바일 앱, 아두이노 스마트 쓰레기통, 그리고 Flask 백엔드가 연동되어 동작하는 구조로  
사용자가 QR을 스캔하고 쓰레기 사진을 촬영하면 AI 분석 → 포인트 적립 → 쓰레기통 동작까지 이어지는  
엔드투엔드 분리수거 시스템입니다.

백엔드는 이미지 분류(AI), 재활용 로그 기록, 포인트 처리, 쓰레기통 제어 신호,  
실시간 SSE 피드백 등 시스템의 모든 핵심 로직을 담당했습니다.

본 프로젝트는 모델 연동 → API 설계 → DB 모델링 → 실시간 피드백까지
백엔드 전반을 단독으로 설계·구현한 프로젝트입니다.

---

## 🛠 Tech Stack
- **Language**: Python 3  
- **Framework**: Flask  
- **Database**: SQLite / MySQL  
- **AI Model**: YOLO 기반 ONNX Model  
- **API Style**: REST API  
- **Others**: Server-Sent Events(SSE), OpenCV, ONNX Runtime  

---

## ⚙️ 시스템 구조
사용자 모바일 앱 → 백엔드 서버 → 아두이노(쓰레기통) → 백엔드 → 모바일 피드백 으로 이어지는 구조.

1) **사용자 모바일 앱**
- QR 스캔 → 사용자·쓰레기통 정보 획득
- 쓰레기 사진 촬영 → 서버에 업로드

2) **Flask 백엔드**
- ONNX 모델로 이미지 분류  
- 재활용 로그 저장 및 포인트 적립  
- 아두이노로 쓰레기통 개방 신호 전송  
- SSE로 모바일에 실시간 피드백 반환  

3) **Arduino (쓰레기통)**
- 백엔드가 보내는 성공 신호를 받아 쓰레기통 개방  
- 동작 결과를 다시 서버로 전송할 수 있는 구조  

---

## 🌟 주요 기능

### 회원 관리
- 회원가입 / 로그인  
- 사용자 정보 조회  

### 분리수거 가이드 (AI)
- YOLO ONNX 기반 이미지 분류  
- 분류 결과를 가이드 형태로 제공  

### 재활용 로그 관리
- 성공 / 실패 여부 기록  
- 사용자별 재활용 이력 조회  
- 포인트 적립 로직 포함  

### 실시간 피드백 (SSE)
- 쓰레기 투입 성공 시 즉시 모바일에 알림 발생  
- AI 분석 → 포인트 적립 → 쓰레기통 동작까지 실시간 반영  

### 쓰레기통 관리
- QR 기반 쓰레기통 식별  
- 쓰레기통·세트 등록/조회

## 👤 My Role (방혁) — Backend Developer
백엔드 전체 구조 및 로직을 모두 설계하고 개발했습니다.

### AI 모델 연동
- YOLO ONNX 모델 로딩 + OpenCV 이미지 처리  
- ONNX Runtime 기반 추론 파이프라인 구축  

### 재활용 로그 & 포인트 시스템
- 로그 저장/조회, 성공·실패 판정  
- QR 기반 사용자인증 흐름과 포인트 적립 로직 구현  
- 사용자별 기록 제공 API 개발  

### 아두이노–백엔드 실시간 연동
- 모바일 앱 → 서버 → 아두이노로 이어지는 삼자 연동 처리 흐름 설계  
- 쓰레기투입 성공 시 아두이노로 동작 신호 전송  
- 아두이노 응답을 서버에서 받고 SSE로 모바일에 피드백  

### 실시간 피드백 (SSE)
- SSE 기반 비동기 스트리밍 구조 구축  
- 투입 결과를 모바일 앱에 실시간 전송  

---

## ✔️ Summary
Yobunjung은 모바일 앱–백엔드 서버–아두이노 장치가 실시간으로 상호작용하는 IoT + AI 통합 시스템입니다.

특히 QR 스캔 → AI 분석 → 쓰레기통 개방 → 포인트 적립 → 실시간 피드백까지 이어지는  
삼자 연동 흐름을 안정적으로 구현하는 과정이 가장 복잡하고 도전적인 부분이었습니다.  
아두이노에서 발생한 센서 이벤트를 서버가 처리하고,  
그 결과를 SSE로 모바일에 즉시 전달해야 했기 때문에  
비동기 이벤트 처리, 상태 동기화, 에러 핸들링까지 직접 설계해야 했습니다.

이 과정을 통해 API 개발을 넘어 실시간 이벤트 기반 아키텍처와 IoT 연동 구조 전반을 이해하게 된 프로젝트였습니다.
